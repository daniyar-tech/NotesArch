# NotesArch

## Версионирование приложения

Версия приложения формируется автоматически на основе количества Git-коммитов.

- **versionCode** — общее количество коммитов в Git-репозитории.
- **versionName** — строка формата 2.1.N, где N — количество коммитов.

Для получения количества коммитов используется команда:

git rev-list --count HEAD

После каждого нового коммита номер версии увеличивается. Для корректной работы GitHub Actions используется полная история репозитория (etch-depth: 0).

## Сборка Release

Для сборки Android App Bundle используется команда:

.\gradlew.bat bundleRelease

Для подписания Release-сборки используются переменные окружения KEYSTORE_FILE, KEYSTORE_PASSWORD, KEY_ALIAS и KEY_PASSWORD.
